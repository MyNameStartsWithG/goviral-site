GoViral

A personal clip pipeline by NameIsGuven (@nameisguven)

I'm building a pixel art game using AI and testing every tool along the way. I stream the work on Kick, Twitch and YouTube. GoViral is the small tool that turns those streams into short videos.

What it does

  • Finds the interesting moments in my own stream recordings, using the transcript, chat activity and audio.
  • Cuts them into captioned vertical clips.
  • After I review and approve each clip, it uploads the clip to my own accounts: YouTube (@nameisguven), Instagram (@nameisguven) and TikTok.

Who can use it

Only me. GoViral is not a public service. It connects only to accounts I own, and nobody else can sign in to it.
